# DaysWith v3.1 实施计划

2026-11-03；范围以 [最终需求清单](v3.1-final-requirements.md) 为准。

## 基线与隔离

- 当前源：`Henrypann/DaysWith`，初始提交 `d46d74eed0cdc876dfa23edaa334b0f92dd5c166`，Flutter `3.0.0+11`。
- 独立检出：`DaysWith/`；本地分支 `codex/dayswith-v3.1-foundation`。历史原生 Android 2.1 检出保持原样，不作为新开发入口。
- 新检出没有 AGENTS.md 或仓库 .agents/skills；已检查祖先指令。旧检出和其他 worktree 不修改。
- 无真实云凭据、NAS 服务或授权测试设备；真实服务/跨设备验收目前阻断，不影响合成测试与本地实现。

## 依赖与分批排期

以下是工作包与依赖顺序，不是承诺上线日期；真实服务和平台验收完成后才可给出发布日期。

| 批次 | 工作包 | 依赖 | 并行边界 / 出口 |
| --- | --- | --- | --- |
| 0，基线 | 双平台工具链、Dart/Flutter 分析测试、构建基线、旧版差距 | 无 | 独立基线副本；不与实现源码互相污染 |
| 1，合同 | Provider 能力/目标身份、凭据格式与队列绑定、恢复策略；Family 与邀请域合同 | 基线阅读 | 存储与家庭新文件可并行，主代理统一集成和导出 |
| 2，3.1.0 | Local-first 首次进入、四入口、COS 回归；WebDAV 适配/安全凭据、存储中心与持久任务 | Provider 冻结 | UI 与新适配器分文件；共享 app_model/queue 由一人集成 |
| 3，数据可靠性 | 离线后连接的手动确认、稳定 ID；完整恢复与哈希、目标切换与老格式回归 | 批次 2 | 合成数据隔离恢复，故障注入；测试不得操作真实照片 |
| 4，3.1.x | 可信 Gateway/STS 端点与部署合同、扫码客户端、审批/成员/撤权、版本化 family 清单 | 基础存储、服务端安全设计 | 域模型可提前；真实授权端未验证前入口保持实验阻断 |
| 5，系列验收 | Android/iOS 跨设备 10 图 1 视频；真实 COS/NAS 恢复/撤权；之后 S3 扩展 | 批次 3、4 及受控资源 | 单列通过/失败/未执行；不自动推送、部署或发布 |

## 评审约束

测试仅使用合成媒体/凭据。现有长期 COS 连接保持原命名和安全存储兼容。WebDAV 使用独立安全存储项，不把密码放档案。拒绝跨目标复用队列；切换不自动迁移旧对象。家庭域测试服务不是可信授权后端，客户端不自行签发真实权限。缺少条件写入、安全授权或完整恢复证据时如实阻断。每批记录可复现命令、实际结果与剩余缺口。
