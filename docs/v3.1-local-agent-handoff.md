## 执行位置与低负载验收顺序

根目录 [AGENTS.md](../AGENTS.md)、[EXECUTION_RULES.md](../EXECUTION_RULES.md) 是固定规则：日常开发、依赖准备、分析、批量测试、服务端和 Android 构建默认在云端。Mac 只承担明确授权的必要 Xcode/iOS 或真机验收；不能因云端网络问题把整套开发搬回 Mac，也不自动联系或唤起 Mac。

1. **先轻量核对源码与资源。** 在执行平台记录磁盘剩余、物理/可用内存、内存压力、现有编译/模拟器进程；Mac 可用 `df -h`、`sysctl -n hw.memsize`、`vm_stat` 和 Activity Monitor。若磁盘或内存不足，停止大任务并报告；不擅自清理用户文件、缓存或现有进程。
2. **先解决云端工具链。** 当前云端没有 Flutter/Dart，`storage.googleapis.com` 不在受支持的已执行网络许可中；一次官方元数据 HEAD 返回 `Tunnel connection failed: 403 Forbidden`。这是代理网络拒绝，不是自动审批拒绝。通过正式环境配置修复并核验后，再准备 Flutter 3.47.8 / Dart 3.13.7 或经过兼容性核验的官方版本；不改代理、不用不明镜像、不降低 SDK 约束。JDK 17、Android SDK 37/Build Tools 36.0.0 已在云端，但未完成构建。
3. **云端逐项闭合客户端检查。** 先核对 `flutter --version` 和依赖约束，逐个包执行 pub get，审查新增扫码依赖及锁文件变化。再做格式检查/分析，先跑作用域、upload_intent、family_archive/client、family_data_controller 与 UI 回归，再完整回归。初始 test concurrency 不超过 2，一次只跑一项大任务；既有 info、失败和未执行项分开记录。只有实际命令退出和结果才是证据。
4. **云端 Android 编译。** 保持仓库 Gradle 的 2 workers、3 GiB heap/1 GiB metaspace 上限，仍要按实际预算降低；一次仅一个构建。默认测试构建，无发布签名或分发。SDK、锁文件、依赖和插件问题解决后才生成受控安装包，不把编译成功当运行验收。
5. **另行授权后才做 Mac 必要阶段。** 先重查资源，单个 iOS 构建/模拟器或隔离真机任务，逐项验证 CocoaPods、iOS 16+、相机和照片权限、扫码、图片/视频生命周期。不得同时启动多平台大构建。无签名编译不能替代安装；覆盖升级需原 bundle/package ID、Keychain service/路径与原签名，不能改标识规避迁移问题。
6. **资源就绪后进行真实闭环。** 需要合法 App 登录会话、明确 issuer/audience/JWKS、受控 HTTPS/Host、持久 DB 和专用 NAS 目录，或经审查的兼容 COS 写入适配器、隔离桶和最小权限身份。生产凭据、部署和扩权另获授权。用隔离合成身份/10图1视频，逐项记录跨 Android/iOS 审批、权限拒绝、撤权/缓存、离线重启、失败重试和完整恢复的数量、SHA/大小、文字/日期/归属；旧记录和原片不得删除。
