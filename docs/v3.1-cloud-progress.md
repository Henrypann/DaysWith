## 本轮新增与修复

- 队列创建、恢复校验和 App 状态使用完整 provider/endpoint/accountScope/writer-prefix 目标身份；同一 NAS URL 的不同账号不能复用任务或显示旧账号任务。
- 上传意图写入串行化；暂停会同步持久化 `uploadPaused`，并以 generation 阻止异步回调重新授权。即使偏好清除尚未完成/失败，重启也不自动恢复已暂停任务。档案暂停写入失败会明确报错。显式重新确认才解除暂停。
- 增补 `upload_intent_test.dart`，覆盖慢偏好保存、网络等待、重启、冻结记录、目标/账号变化、配置取消、同步监听器暂停和本地保存失败。
- schema 升级前保留独立、按原字节 SHA-256 命名的旧版档案副本；正常 recovery 轮转不会覆盖该副本。没有自动回滚或原地清除旧数据。
- WebDAV 下载拒绝已有/悬空链接，核验实际父目录；隔离恢复使用固定规范路径。纯 Dart 的最终检查/rename 仍不构成对恶意同 UID 并发写入者的绝对保护。
- 增加 SQLite Family Gateway：独立身份校验注入、持久一次性十分钟邀请、预览确认、待审批、三角色、设备关联、记录归属、修订冲突、撤权与审计。默认没有身份验证器，失败关闭。
- 增加隔离目录对象网关：流式、内容寻址、哈希/大小校验、不可覆盖、每次及传输中授权重查；删除先写审计意图。它是本地/挂载目录实现，不是已接通的 WebDAV 网络代理。
- 增加受限只读 COS STS 策略与签发适配边界，默认关闭；没有真实签发器或生产凭据。写入仍经网关，不能用普通 COS PUT 冒充不可覆盖原件。
- 增加 HTTPS 家庭客户端和创建/成员/邀请/审批/撤销界面、二维码与相机扫码；App 只接受已认证 host 注入的客户端，未配置时明确阻断。扫码不会打开任意网址或授予本地权限。
- 增加 family/v1 版本化档案合同、成员与设备命名、稳定资源 ID、完整性元数据、链和冲突规则及只读旧版复制/回退计划。仍未接入服务端记录表导出、App 家庭上传与完整恢复。
- Android 改用官方 Gradle/Maven 来源，Gradle 9.3.1 官方 SHA-256 与原锁值一致；默认 Gradle heap 降为 3 GiB、metaspace 1 GiB、workers 2。
