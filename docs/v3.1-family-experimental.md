# V3.1 家庭与邀请领域契约（实验性）

本批次只提供纯 Dart 模型、权限规则、邀请网关接口与内存参考测试服务。代码不接入现有 App，不改变 Dad/Mom 旧档案，不生成云端密钥，也没有生产授权能力。

代码：`flutter/jinbao_core/lib/src/family.dart`、`family_invitations.dart`。测试：`test/family_permissions_test.dart`、`test/family_invitations_test.dart`。

## 领域与权限

- `Family.id`、`FamilyMember.id` 是稳定 UUID；昵称、爸爸/妈妈等关系标签仅供显示，不能作为身份、对象路径或权限依据。
- `FamilyActor.subjectID` 是未来网关完成身份验证后传入的主体。参考服务信任调用方输入，不能把创建一个 `FamilyActor` 当作已认证。
- 活跃家庭成员可读记录。管理员、贡献者可新增记录及编辑自己成员 ID 所属的记录；查看者不能新增或编辑。管理员也不会隐式获得编辑他人记录的权限。
- 管理成员、发邀请、审核加入申请仅管理员可用。跨家庭、缺失及已撤销成员均拒绝访问。
- 本参考实现不支持通过邀请授予管理员，不实现管理员晋升；这些策略需要独立审核。不能撤销最后一名管理员。

## 邀请流程

`FamilyInvitationGateway` 定义 `issue → inspect → exchange → approve/deny`，并提供邀请撤销、成员撤销、申请状态与权限查询接口。

1. 管理员签发邀请，默认且最长有效期为 10 分钟，可设更短期限。QR 仅包含固定 HTTPS 网关来源下的 `/family-invitations/<随机 token>`。token 为安全随机 256 位值；不含家庭名、角色、密码、SecretID 或 SecretKey。内存中仅保留 token 的 SHA-256 摘要；默认诊断字符串隐藏 token。
2. `inspect` 只读取加入确认信息，展示家庭名称和拟授予角色，不消费邀请，也不授予访问权。非 HTTPS、其他来源、用户信息、查询参数、片段、异常路径和无效 token 均拒绝。
3. `exchange` 要求用户明确确认上述家庭与角色，并在提交时再次校验有效期。有效期边界本身已视为过期。成功后一次性消费邀请，只产生 `pending` 申请，不产生家庭成员。
4. 仅活跃管理员可批准或拒绝。批准后创建成员；拒绝后原邀请仍已消费，不能重放。重复批准失败，不会创建第二个成员。token 的期限限制兑换；已兑换的申请可在期限后继续等待管理员审核，管理员撤销邀请时会取消仍在等待的申请。
5. 撤销邀请会阻止未兑换邀请并取消其待审核申请；不隐式撤销已经批准的成员。撤销成员是另一项显式管理操作，立即停止该参考服务后续权限查询的授权。撤销不删除记录。

参考服务的状态变更无异步暂停点，仅在一个 Dart isolate 的内存里串行执行；测试覆盖并发兑换和并发批准。它没有数据库锁、跨进程事务或重启后的防重放保证。生产网关必须使用持久事务/条件写入，并独立验证调用者身份及权限，不能直接部署这段参考服务。

## 离线、缓存与真实授权边界

所有参考网关调用在 `gatewayAvailable` 为 false 时失败，包括签发、查看、兑换、审核、撤销、状态查询和权限查询。这个输入只是测试控制，不会实际探测网络或验证远端网关。

这不是完整的离线缓存策略。本批次不接入 App 的缓存读取和清理；已下载照片和内容无法靠服务器撤销追回。真实实现需明确本机缓存的保留/隐藏规则、撤销通知时延、再次联网校验，以及临时 STS/网关授权过期前的权限窗口。不能承诺撤销后所有已下载内容立即消失。

仍待实现和验证：真实身份与受信任网关、管理员身份恢复、持久成员/邀请事务、防滥用与审计、COS 服务端 STS 最小权限签发、NAS 网关授权、扫码界面与相机权限、多设备和跨品牌真机联调。二维码中的 HTTPS 网址是敏感的短期邀请，应避免日志、分析上报和无关的 URL 预取。

本批次没有部署、OAuth 授权、新建持久凭据、生产配置或真实家庭数据操作。不能将领域测试通过解释为真实家庭加入或安全授权已交付。
