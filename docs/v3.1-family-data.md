# 家庭记录上传、查看与完整恢复

2026-11-03。本文描述当前开发源码的路径与边界。Python 服务协议已用隔离合成媒体执行；Dart/Flutter 侧仍未编译或运行，不能据此宣布手机端验收完成。

## 数据和授权

已认证的家庭页面从 Gateway 获取当前成员、角色和主要存储 ID。家庭身份、关系和授权不从本机爸爸/妈妈署名推导；旧本机署名只用于筛选这台手机自己的旧版记录。云端成员 UUID、设备 UUID 和资源 SHA-256 构成 `family/v1` 命名，显示名不参与路径。

新家庭成员可直接从相册多选、拍照或录像，无需选择爸爸/妈妈身份。每完成一项导入就同步保存本机原件/预览及草稿元数据，再处理下一项；本地导入不上传。旧版本人记录也可按记录 ID 明确选择复制。

上传前冻结本人记录、原件/预览、文字和纪念日，保存独立草稿，再重新验证当前成员与目标。确认界面固定家庭、数量、大小、网络规则及清单/草稿身份。关闭确认、切换控制器/账号/目标、暂停或取消不会授权后来的内容。复制不会修改原 AppSession、life/v1 数据或系统相册。

`frozen-source.json` 保全尚未准备成功的本地文字/选择；`intent.json` 保存准备好的不可变清单、相对资源路径、成员/subject/设备/目标绑定和状态。所有重启恢复都需要用户明确继续，不自动上传。未读懂的草稿或任务会阻断覆盖，须明确处理；暂停、取消和源文件出错不能伪装成持久成功。等待 Wi-Fi 的请求保持原选择；蜂窝原件下载需设置许可或单次确认。替换已取消或完成的草稿前，原始字节会另存为按哈希命名的本机恢复副本；无法保存副本时拒绝覆盖。无法读取的旧任务日志也先保留，不能用「取消上传」悄悄丢掉仅在本机的文字。恢复副本不会自动重新上传；这类本机历史草稿目前用于受控支持恢复，不自动出现在家庭时间线。

## 上传与发布

1. 新设备通过已认证接口登记，不能占用其他 subject 的设备身份。
2. 逐个验证本机文件的大小和完整 SHA，流式上传内容寻址的原件与预览；已存在对象须经授权 HEAD 精确核验后才能复用。
3. Gateway 在发布事务中重新读取、校验所有引用对象。原件缺失、损坏、越界、权限/版本/归属冲突会拒绝清单发布。
4. 每设备快照有连续序号和父清单哈希；重复提交完全相同清单幂等。跨设备同修订不同内容、旧修订覆盖新修订、复用媒体 ID 指向不同字节均拒绝。
5. 客户端在成功响应后独立读取已发布清单并验证完整字节。上传完成只代表该副本已验证，不等于另一台手机已完成恢复。

快照发布之后，已引用原件不能被普通对象删除接口移除。目录分页水位绑定 subject、家庭、快照上界和审核版本；过期、重放错家庭、截断/重复页及审核状态变化不会悄悄变成成功。

## 家庭查看与管理员审核

家庭列表展示原作者、日期、文字及媒体。新源码提供 `Image.file` 缩略图/原图和文件视频播放器；每次打开先后重新检查成员、存储、审核状态和对象授权，并验证缓存完整字节。后台停止播放；收到授权拒绝或检测到身份/目标变化时停止播放器并清除已显示路径。视频的真实设备解码、播放和生命周期仍待实测。Live Photo 当前只显示静态原图；配对视频保留在完整恢复中，不宣传完整动态播放支持。

管理员可显式确认隐藏/恢复其他成员的记录，服务端单独鉴权与审计。审核覆盖层不重写作者的不可变清单、修订或原件。隐藏期间作者不能用提高修订绕过审核；精确携带原快照仍允许。**隐藏是家庭时光的展示状态，不是内容访问撤销或物理删除**：有权读取家庭历史的成员仍可获取历史原件。撤销成员是另外的权限操作。

缓存绑定网关与当前 bearer 的单向摘要，不保存原 token，不把摘要当作权限。缓存文字先私下暂存，只有同一会话的离线失败才发布为带标记的缓存视图；退出、换会话、401/403 不会先闪现旧账号文字。令牌刷新会保守隐藏缓存，直到在线重新验证同一成员。缓存角色不提供编辑或上传权限。媒体读取没有绕过在线授权，离线不能把缓存路径当作新授权。已下载字节不能靠服务器撤权保证物理追回，系统截图和其他复制同样不能撤回。

## 隔离恢复和重试

恢复只写新建的独立目录，不替换当前 AppSession 或原件。开始联网前通过同步回调持久保存 `.family-restore-*.pending` 路径和目标/身份；断网、暂停、进程退出后可以明确重试。缓存文件每次重新哈希；错误缓存另行隔离，只有本次创建的临时文件可清理。

恢复遍历完整分页目录、校验全部设备链、归属、修订冲突、媒体 ID、审核层和所有原件/预览。目录/审核水位变化会使当前恢复冲突，不能报告部分成功。核心恢复完成改名后，App 先清除旧 `.pending` 指针并保留未确认完成凭据，再进行额外身份复查；后续断网不会把已完成目录误当作可续传阶段。

输出保留原始 canonical 快照、合并记录、纪念日、对象映射、审核覆盖层和校验事实；所有字节和最终在线授权通过后才生成完成凭据并发布目录。

空目录没有可恢复备份，不能拿 0 对象完成标记冒充备份成功。恢复结果保留作者 UUID，显示可见记录与历史原始记录的区别；没有因下载原件获得修改他人记录的权利。

默认保护上限包括 10000 个快照描述、64 MiB 恢复清单总量、8 MiB 合并导出元数据和 8 GiB 恢复媒体；App 显示缓存另有 8 MiB 清单预算。超限明确失败，不静默截断；这些限制需要在更大数据量验收后调整。

## 当前验收边界

完整 Python 套件及源文件哈希记录在 [v3.1-verification.json](v3.1-verification.json)。可执行向量使用 10 张有效小 PNG、1 段本地生成 MP4 和 11 个预览，通过 WSGI 写入、重建 Gateway 实例并恢复到独立临时目录，逐对象比较字节、大小和 SHA。它们不是 HTTPS 网络、真实 NAS/COS、Android/iOS、真机权限或跨手机验收。

真实身份接入见 [family-identity.md](family-identity.md)，服务协议与 COS/STS 阻碍见 [family-gateway.md](family-gateway.md)。没有启动监听器、部署、安装真实凭据或操作家庭照片。
