# DaysWith v3.1 最终需求清单

日期：2026-11-03。依据：Henry 在本次会话提供的两份 PRD，经主线程去重、按更具体的 V3.1 约束收敛。本文是本轮范围合同；实现状态与验收证据另记，不以计划代替完成。

DaysWith 是 Local-first 的家庭成长记录工具。3.1.0 交付 Storage Foundation，3.1.x 继续 Family Sharing；仅完成基础存储不能代表整个 v3.1 系列完成。

## 3.1.0 必做

| ID | 最终需求 | 验收边界 |
| --- | --- | --- |
| BASE-01 | 核对 Flutter 3.0.0+11 基线，分别审计 Android/iOS、分析、测试、构建与可获得的真机流程 | COS 连接、导入、备份、读取、失败恢复分别记录；不能用原生 Android 结果代替 Flutter/iOS |
| LOCAL-01 | 新手入口「开始记录」「加入家庭」，无网无云仍可创建与编辑文字、原始照片/视频、时间线、纪念日 | 重启保留；清楚显示「仅保存在本机」；后连存储保持记录 ID、不得重复历史记录；授权服务未就绪时加入家庭如实阻断 |
| STORE-01 | 统一 Storage Provider：连接、分页列举、流式上传/读取、stat、按权限删除、健康检查、超时、安全重试、校验 | 业务不依赖 COS/WebDAV 特有字段；能力显式描述条件写入与版本差异；大文件不整体加载内存 |
| STORE-02 | 保留 COS，新增 HTTPS WebDAV NAS；连接名、URL、专用账号、密码安全保存、专用目录、证书及读写检查 | 禁止明文密码传输和跳过 TLS；可沿用用户已有 VPN/隧道，不配置公网穿透；不可达不挡本地编辑，任务持久等待；容量未知时显示未知 |
| STORE-03 | 存储中心展示单一主要目标、健康、最近成功备份、待处理/失败/校验任务、错误与重试 | 切换不自动迁移、合并、删除旧后端；不得假造成功或空间 |
| MEDIA-01 | 手动多选原图/视频；传前确认数量、大小与目标；Wi-Fi 优先 | 仅本地、等待、上传中、校验中、已验证远端副本、失败；前台退出、断网、容量满、认证过期不假成功 |
| MEDIA-02 | 原件/缩略图分开，稳定媒体 ID、SHA-256、大小、记录关联；持久幂等重试 | 缺失/损坏不标成功；上传成功不等于完成独立恢复验证 |
| RESTORE-01 | 隔离环境或另一受控设备从清单和原件重建完整时间线 | 验证文字、原件、纪念日及编辑归属，不用预览替代恢复，不覆盖唯一原件 |
| COMPAT-01 | life/v1、爸爸/妈妈、既有档案与凭据保持兼容，schema 版本化 | family 命名空间必须有清单、命名、冲突规则与兼容向量；迁移为复制、校验、切换、可回退，不做破坏性原地覆盖/自动清旧副本 |

## 3.1.x 本轮后续必做

| ID | 最终需求 | 验收边界 |
| --- | --- | --- |
| FAMILY-01 | Family/Member 稳定 ID、家庭名、管理员、昵称/关系、权限角色、加入状态、设备关联，祖父母及自定义关系 | 关系只是显示；保留老爸爸/妈妈协议兼容；一个家庭一个主要可写目标 |
| INVITE-01 | 安全扫码邀请，默认 10 分钟一次性，确认家庭名及申请权限，管理员审批后受限授权 | 过期、离线、重复/并发兑换、拒绝、撤销测试；无重复成员/离线假授权；二维码不得有长期 COS SecretKey/NAS 密码 |
| AUTH-01 | 可信授权服务；管理员、投稿成员、查看者；普通成员仅编辑自己的记录 | 删除共享记录/原件、成员撤销为独立权限并审计；COS 服务端受限 STS；NAS 可用轻量自托管 Family Gateway/必要代理；单人 NAS 直连独立可用，不能共享长期密码模拟授权 |
| AUTH-02 | 撤销阻止新授权并撤销可撤销凭据 | 明确临时凭据有效期窗口、已缓存内容不能保证物理删除；不能满足安全要求则保留实验状态并阻断 |
| CROSS-01 | Android/iOS 家庭读取、上传、编辑归属、换机完整恢复与撤权 | 10 张合成照片、1 段合成视频；中断、重试、独立恢复、哈希验证；mock 不代表真实端到端 |
| EXT-01 | S3-compatible NAS/对象存储适配 | 排在完整授权闭环之后；不能把 WebDAV/NAS 宣称为 S3 支持 |
| UI-01 | 时光、记录、回忆、我的四入口；我的统一家庭空间/数据与存储；家庭首页、邀请审批、成员管理 | 老人常用看/加照片突出，大字体和点击面积；技术设置面向需要的管理员，不丢已有功能/无必要视觉重构 |

## 不属于本轮完成门槛

系统相册原件清理（仅预留校验/可恢复性接口）、持续后台/自动同步、双存储备份、Memory Film、AI 精选/旁白、SMB。不得删除真实原片、迁移生产数据或更改生产配置。未来正式清理须完整哈希、独立恢复验证、额外副本提示、系统删除确认；本轮不提供稳定清理能力。

前台同步可以展示时间、离线与失败；不承诺实时或后台常驻。不引入第三方埋点或上传家庭数据；指标仅定义本地可观测事件与分母。禁止「零隐私风险」「永久安全」「一行部署即安全共享」等保证。

## 发布门槛与授权

Flutter 双平台结果分别记录，COS 回归、真实 HTTPS WebDAV 上传/读取/恢复、离线重启、旧版兼容均须通过，无已知原件丢失阻断，README 与实测一致。缺设备、真实服务或授权的项目标记未执行，不能用 mock 或编译结果替代。实施/测试/文档可自主推进；真实凭据、扩权、购买、生产部署、生产迁移/删除不在授权内。本轮仅保留可审查本地结果，不 push、merge 或发布。
