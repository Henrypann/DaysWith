# DaysWith 4.0 宣传短视频

两支短视频都由仓库里的代码生成：手机画面是 **真实的 4.0 Flutter 界面**，在 `flutter test` 里逐帧渲染后交给 ffmpeg 编码；照片是代码绘制的合成插画，记录是虚构的，配乐由脚本合成。没有家庭照片、真人肖像、第三方素材或真实云端请求。

| 版本 | 画幅 | 时长 | 受众与渠道 | 一句话 |
| --- | --- | --- | --- | --- |
| A「她的每一天」 | 9:16，1080×1920 | 32 秒 | 国内爸妈；小红书、抖音、视频号 | 两万张照片里，找回她第一次坐稳的那天 |
| B「你的照片，不该交房租」 | 16:9，1920×1080 | 31 秒 | 开发者与重视数据自主的人；GitHub README、B 站、X | 开源、本地优先、自带存储，没有会员订阅 |

## 生成

需要 Flutter（Dart `^3.13.7`）、Node.js、ffmpeg，以及一款中文字体（默认找 Windows 的 Noto Sans SC，也可用 `PROMO_FONT` 指定字体文件）。

```sh
cd flutter/jinbao365_app
node promo/music.mjs ../../promo/out          # 合成两段配乐
PROMO_FFMPEG=/path/to/ffmpeg flutter test promo/video_a_test.dart
PROMO_FFMPEG=/path/to/ffmpeg flutter test promo/video_b_test.dart
flutter test promo/preview_test.dart           # 只出静态截图
```

成片写入 `promo/out/`（不入库）。演示数据的日期都相对「今天」生成，所以「那年今天」和纪念日倒数总有内容。

## 宣传口径

视频只说代码里已经有的能力，并把 README 里的边界带进画面：

- 不说「无缝换机」「跨品牌已验证」「端到端加密」「后台自动备份」「系统通知提醒」。这些要么未实现，要么未完成验收。
- 「没有会员订阅」不等于免费：自有云存储的费用由云厂商收取，B 版用「¥0 会员订阅」表述。
- B 版在存储一幕写明：当前适配腾讯云 COS、暂无端到端加密、备份在应用前台进行。
- 两版落版都标注：演示画面为合成插画与虚构记录；项目在开发中，需自行构建。
- 成长卡片是屏幕重绘的图片，不带原照片的位置和拍摄信息；这句话可以说，因为它由实现方式保证。
